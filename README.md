## Features

- Light and dark theme, with the visitor's choice remembered
- Fully responsive, so it works on phones, tablets and desktops
- Project filter (All, Mobile, Automation) and project detail popups
- Contact form that opens your email app with the message ready to send
- "Copy email" button and a Gmail shortcut
- Rotating quotes about coding and programming
- Smooth scrolling, scroll animations, and a back-to-top button
- Respects the "reduce motion" setting for accessibility

## Built with

- HTML, CSS and vanilla JavaScript, all in a single `index.html` file
- No frameworks, no build step, no dependencies
- Google Fonts (Space Grotesk and Instrument Serif)
- Hosted free on GitHub Pages

Design inspiration: the [Sawad portfolio template](https://sawad.framer.website/) on Framer. This version is rebuilt from scratch with its own layout, colors and content.

## Run it locally

1. Download or clone this repository.
2. Open `index.html` in any web browser.

That's it. There is nothing to install.

## Customize it

All of the content lives in one block near the bottom of `index.html`, marked `EDIT THIS BLOCK`. Change the text inside the quotes to update:

- `name`, `email`, `github`, `linkedin`, `role`, `location`
- `about`: the paragraphs in the About me section
- `bg`: the Education and Approach cards
- `comps`: the technical competency groups
- `projects`: the project cards and their details
- `journey`: the timeline
- `quotes`: the rotating quotes

Keep the quotation marks, commas and brackets exactly as they are, and change only the words between the quotes.

## Deploy with GitHub Pages

1. Put `index.html` at the top level of the repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and `/ (root)`.
4. Save, wait a minute or two, and open the link GitHub shows.
